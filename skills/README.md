# Skills Library

This folder contains structured AI/agent skill files — focused, expert-persona prompts designed to be dropped directly into an AI coding assistant, Claude Project, or agent workflow.

## Folder Structure

```
skills/
└── al-performance/     AL (Business Central) development performance skills
```

## File Conventions

Each skill file follows the standard Prompt.Library format:

- **Role definition** — Expert persona with domain and experience framing
- **Objective** — Single-sentence mission statement
- **Methodology** — Numbered analysis framework covering all relevant areas
- **Output format** — Explicit markdown template with section headings
- **Constraints** — Hard rules the skill must always follow
- **Examples** (where applicable) — Sample input/output demonstrations

## Usage

Paste the full content of a skill file as a system prompt or at the start of a conversation. The skill primes the model with domain expertise and enforces consistent, structured output.
